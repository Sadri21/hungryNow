HungryNow — App Mockups, First-Run Flow

Splash → Welcome → Permission → Home → Loading → Result

Built on the locked Pomegranate & Pistachio spec — real screens in real phone frames, not just color swatches, so the flow reads the way an actual first launch would feel.

Why Screen 1 is nearly blank: Apple's HIG is explicit that a launch screen is not a branding moment — it should look almost identical to the first real screen (same background, no text since it can't localize) so the transition feels instant rather than jarring. The actual "hello" moment is Screen 2, right after — that's the correct place for it, and it's what a reviewer would actually judge as the app's first impression.
