First-run flow

Each screen is its own file, sharing one stylesheet. Edit a screen without touching the others; edit shared.css to change the design system everywhere at once. This page just embeds them, so it always reflects the current state of each file.

State, 2026-09-08: all nine screens are designed. Screen 06 was restructured heavily — edge-to-edge media, a snap carousel, no app bar — and is the only screen anyone has actually looked at rendered. 02, 03 and 08 have changed and have not been seen. None of them have a dark-appearance pass yet. If an embed below looks blank, your browser is blocking local iframes; click the screen title to open that file directly.
