HungryNow — Visual Identity

Pomegranate & Pistachio

One system, two required appearances. Deep pomegranate red marks the single hero recommendation; soft pistachio green marks the specialty picks — the color alone tells the tourist which of HungryNow's two answers they're looking at, before they read a word.

Landed here after five rounds of options (15 palettes total): "Night Ledger" was too dark/formal, its replacement "Golden Hour" turned out too close to the generic warm-neutral palette a lot of AI tools default to. Blue/teal/navy got eliminated in every round it appeared. Pomegranate & Pistachio is the jewel-toned finalist — grounded "Rust & Mustard" is kept as a fully-specified, swappable backup (see bottom of page), built on the same token names so switching later needs no code changes.

Swappable backup — same token names, different values

Rust & Mustard

Kept fully specified so switching mid-development is a value swap in the Asset Catalog, not a redesign. Rust (hero) + mustard (specialty) on warm neutral gray — grounded, spice-market, less sweet than the primary. Full light + dark tables with contrast ratios: wiki/concepts/visual-identity.md.
